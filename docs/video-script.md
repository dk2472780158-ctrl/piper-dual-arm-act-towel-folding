# 视频脚本与分镜

三份视频面向具身智能算法岗位面试与开源展示，共同遵守两条纪律：

- **报告口径**：只写「在一次连续录制的实验中，系统完成 10 次测试并成功 10 次（10/10 consecutive trials）」，不写「成功率 99%/100%」。
- **视频诚信**：连续十次版本为一次不间断拍摄、保留时间线、标记 Trial、注明人工复位；变速片段必须标注。

三份视频都在同一套真实硬件与同一 checkpoint（部署所用 global step 040000，run `towel_fold_act_v4_scratch60k`）上拍摄。

---

## 视频 1 · Hero Demo（30–60 秒）

**用途**：README 顶部 / 面试开场。只留精华，节奏快。

### 分镜

| 时间 | 画面 | 字幕/旁白 |
|---|---|---|
| 0–4s | 全景：双 Piper + 毛巾工作台，标题「Dual-Arm ACT Towel Folding」 | ACT · 双臂 · 真实硬件 |
| 4–20s | 一段完整叠毛巾（正常速度） | 单模型预测整段动作块（chunk 100 → 执行 30 步/次） |
| 20–40s | 第二次叠毛巾，穿插 2× 加速与 0.5× 关键抓取慢放 | 双臂协同 · 柔性物体 |
| 40–52s | 关节/图像观测叠加画面（28 维状态 + 三目相机） | obs.state 28 · 三目 640×480 |
| 52–60s | 收尾：3 个成功片段拼接 + 「10/10 consecutive trials」卡片 | 单次连续录制 · 10/10 |

**剪辑要求**：Hero 允许拼接多个成功片段（它不承担「连续性」证据）；若混入慢放，必须打 `0.5×` 角标。

## 视频 2 · 连续十次完整版（完整时间线）

**用途**：唯一承担「10/10」证据的视频。**一次不间断连续拍摄，不剪辑**。

### 结构

| 元素 | 要求 |
|---|---|
| 开场 | 黑场 1–2s，字幕「单次连续录制 · 无剪辑 · 同一 checkpoint」 |
| Trial 01–10 | 每次试验前插入 `Trial NN` 角标；如需人工复位，立即在画面上注明 `manual reset` |
| 计时 | 每段保留自然时长；试验间人工复位时间可保留但必须可见、可辨识 |
| 结尾 | 定格卡片：「10/10 consecutive trials — one continuous take」 |

### 录制清单

- 固定机位（或至少保证每次试验同机位、同光照），清晰拍到双臂与毛巾初始/结束状态。
- 逐次记录 `video_start_time` / `video_end_time` / `manual_reset_required`，回填 `results/consecutive_10_trials.csv`。
- 全程保留系统时间戳，便于与 CSV 交叉核验。

**发布形式**：原始 mp4 不入库；仓库放封面图 + 外链（B 站/YouTube 私有或公开），必要时放低码率代理版。

## 视频 3 · 技术分析（60–90 秒）

**用途**：展示对系统的理解深度，含**真实失败案例**（比全成功更可信）。

### 分镜

| 时间 | 画面 | 讲解点 |
|---|---|---|
| 0–8s | 架构流程动画（复用 architecture.svg 元素） | 数据→训练→推理→部署闭环 |
| 8–20s | 数据采集片段 + 28/14 维标注 | 遥操作、单位制修正、obs/action 约定 |
| 20–38s | ACT 训练超参数表 + 推理对比 | chunk 100/50/30、weighted_average、30 Hz |
| 38–52s | 安全层逐条演示：起点拒绝、步长拦截、跟踪停机 | 每个动作先过校验再下发 |
| 52–72s | 2–3 个真实失败片段 + 失败分析表 | 阶段、现象、原因、处置（如实标注） |
| 72–90s | 复盘：边界与下一步 | 起点容差、鲁棒性、基线对比（标注待确认） |

**诚信要求**：失败片段不得美化为成功；凡标注「待确认」的结论（单步耗时、训练墙钟、基线对比）不得在旁白里当成事实。episode 数（120 条 demo）与 GPU 规格（A10 / 24 GB）已确认，可作事实陈述。

## 通用隐私与安全检查单（三份视频共用）

- 画面中不得出现人脸、可辨识人员、电脑屏幕、用户名、IP、设备序列号、机柜标签。
- 音频如含环境人声，要么静音要么全程合法授权；技术分析可用合成旁白。
- 不得出现未经允许的第三方软件界面 / 商标特写。
- 确认前不得上传任何视频到公开平台（红线第 7 条）。
- 仓库只保留 GIF / 封面 / 链接；原始视频不进 git history。
